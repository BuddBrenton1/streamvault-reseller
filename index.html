DNS / Server URL

This is the IPTV server URL your clients' app will connect to. Your clients never see this URL — they only enter their username, password and your provider code.

When you update this, all your clients get the new server automatically on their next app launch. No action needed from them.

ℹ How to find your server URL

Your IPTV provider gives you an Xtream Codes URL that looks like:
http://provider.com:8080

Use exactly that URL here. Do not include your username/password in this field.

Help & Setup Guide
Getting started
  1. Go to DNS / Server and enter your IPTV server URL
  2. Go to My Code and copy your provider code
  3. Share the code with your clients along with their username and password
  4. Clients download StreamVault, enter the code + their credentials and connect
  5. To change your server URL at any time — just update DNS. All clients update automatically.
What to tell your clients
"Download StreamVault from [your download link].
Open the app and enter:
• Provider Code: your code here
• Username: [their username]
• Password: [their password]
Then tap Connect."
